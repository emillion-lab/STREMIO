# STREMIO

Тестова платформа за аудио дескрипция от субтитри — четец за хора с
увредено зрение. Тук живее парсерът и всичко, което го проверява.

Звуковата част (TTS, диаризация, миксиране) идва по-късно.

## Бърз старт

```bash
git clone https://github.com/emillion-lab/STREMIO.git
cd STREMIO
pip install pytest
python -m pytest
```

Нула зависимости за самия парсер — само стандартната библиотека.
Python 3.10 или по-нов.

## Тест с истински субтитри

```bash
python -m tools.check path/to/file.srt
```

Изкарва статистиката и първите реплики с разпознати говорители.
`*.srt` е в `.gitignore` — свалените субтитри не влизат в репото.

Ключовото число е `coverage`. Под 0.1 значи, че файлът не е SDH и
трябва да се търси версия с етикети (в OpenSubtitles: филтърът
hearing impaired).

## Какво прави парсерът

| | |
|---|---|
| `srt.parse(text)` | списък от `Cue` с таймкод, реплики и звуци |
| `srt.anchors(cues)` | само явните имена — котвите за диаризацията |
| `srt.stats(cues)` | покритие, брой говорители, времетраене |

Три форми на SDH етикет се разпознават: `MARTA:`, `[MARTA]`, `- MARTA:`.

Две неща, които струваха бъгове и затова имат тестове:

- `[DOOR SLAMS] Get out.` не е говорител на име DOOR SLAMS. Решава се
  на два прохода — първо се събират безспорните `ИМЕ:`, после скобите
  се съдят спрямо тях.
- Тире в началото на ред значи смяна на говорителя. Там предишното име
  не се пренася напред.

Пренесените имена (`line.inferred`) и родовите (`MAN`, `WOMAN`) не
влизат в `anchors()` — на тях не може да се стъпи.

## Фикстури

`fixtures/*.srt` са измислени реплики, не са от филм. Покриват
форматите, не съдържанието. `messy` се строи в паметта в теста, защото
git нормализира точно байтовете, които тя проверява (BOM, CRLF).

## Правно

Проектът се прави за достъпен формат по смисъла на Директива (ЕС)
2017/1564 (Маракеш). Чужди субтитри не се комитват и не се раздават —
`.gitignore` го налага.
